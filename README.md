# 💡 Bare‑metal lamp controller (STM32G0, LL+CMSIS)

Проект управления освещением на STM32G031 с использованием **только LL‑драйверов и CMSIS** (без HAL).  
Реализовано плавное включение двух монохромных ламп и одной RGB‑лампы с независимой регулировкой яркости.

## ✨ Возможности

- Два независимых канала монохромного света (Lamp1, Lamp2).
- Один канал RGB (красный, зелёный, синий).
- Плавное включение ламп с настраиваемым конечным уровнем яркости.
- Изменение яркости кнопками с автоматическим реверсом при достижении предела.
- Программный антидребезг и удобное управление через битовые флаги состояния.
- Полностью ручная конфигурация тактирования и периферии (никаких `HAL_Init()` или CubeMX‑кода в рантайме).

## 🔧 Аппаратная часть

### Используемое железо

- **Микроконтроллер**: STM32G031 (семейство STM32G0x1, ядро Cortex‑M0+).
- **Плата**: любая плата с данным МК (проект тестировался на отладочной плате с кварцем? укажи здесь, если нужно).
- **Выходы ШИМ** (подключаются к силовым ключам/драйверам ламп):
  - PA0 → TIM2_CH1 – Lamp1
  - PA1 → TIM2_CH2 – Lamp2
  - PA2 → TIM2_CH3 – LampR (красный)
  - PA3 → TIM2_CH4 – LampG (зелёный)
  - PA4 → TIM14_CH1 – LampB (синий)
- **Кнопки управления** (подтяжка к земле через LL_GPIO_PULL_DOWN):
  - PA5 – Вкл./выкл. Lamp1
  - PA6 – Яркость Lamp1 (удержание, только при включённой лампе)
  - PA7 – Вкл./выкл. Lamp2
  - PA8 – Яркость Lamp2
  - PA11 – Вкл./выкл. RGB‑лампы **и** изменение яркости красного канала
  - PC15 – Яркость зелёного канала (только при вкл. RGB)
  - PC14 – Яркость синего канала (только при вкл. RGB)
  - PA12 – зарезервирован, не используется в коде (настроен как вход)

### Схема подключения (упрощённо)

> **Внимание**: все пины кнопок настроены с внутренней подтяжкой вниз, поэтому кнопки должны замыкаться на линию `+3.3V`.

## ⚙️ Программная архитектура

### Тактирование

- Источник: HSI (16 МГц).
- PLL: ×8, ÷2 (R) → **SYSCLK = 64 МГц**.
- AHB и APB1 без предделителя (64 МГц).
- Flash latency = 2.

Все настройки RCC выполнены вручную через LL‑макросы в `main()`, без использования внешних конфигураторов.

### Таймеры и ШИМ

| Таймер | Назначение                          | Частота ШИМ / период прерывания |
|--------|--------------------------------------|----------------------------------|
| TIM2   | ШИМ для Lamp1, Lamp2, LampR, LampG  | 64 МГц / 64 / 128 = **~7.8 кГц** |
| TIM14  | ШИМ для LampB                       | те же ~7.8 кГц                   |
| TIM3   | Системный таймер (1 мс)             | 64 МГц / 64 / 1000 = **1 кГц** (период 1 мс) |

Переменная `microsec` (на самом деле счётчик миллисекунд) инкрементируется в `TIM3_IRQHandler`.  
Все временны́е задержки (`> 150`, `> 20`, `> 10`) выражены в миллисекундах.

### Логика работы

Состояние каждой лампы хранится в битовой маске (биты: включена, идёт старт, пауза нажатия, флаг нажатия кнопки включения, флаг нажатия кнопки яркости).

- При нажатии кнопки включения (удержание >150 мс) лампа либо плавно зажигается до значения `brig_now_lamp_X` (126 по умолчанию), либо резко гаснет.
- Плавный розжиг: каждые 10 мс яркость увеличивается на 1.
- Регулировка яркости: при удержании соответствующей кнопки яркость меняется каждые 20 мс с автоматическим изменением направления при достижении 0 или 127.
- Для RGB все три канала управляются независимо (красный – PA11, зелёный – PC15, синий – PC14).

## 📁 Структура репозитория
Проект **не содержит** сгенерированных CubeMX файлов, достаточно добавить `main.c` в чистый проект STM32CubeIDE (см. ниже).

## 🚀 Сборка и прошивка

### Для STM32CubeIDE (рекомендуется)

1. Создайте новый проект для вашего МК (`STM32G031K8`, `STM32G031F8` и т.п.), выбрав **Target Language: C**, **Library: LL**.
2. Замените автоматически созданный `main.c` в `Core/Src/` содержимым из этого репозитория.
3. Убедитесь, что в свойствах проекта включена оптимизация `-O0` или `-Og` (для отладки) и что линкер скрипт соответствует объёму памяти.
4. Соберите проект (Project → Build All).
5. Прошейте через ST‑Link (Run → Debug / Run).

### Альтернативные среды

Код не зависит от конкретной IDE – он использует только CMSIS‑файлы и заголовки LL. Для сборки под GCC достаточно добавить пути к CMSIS‑пакету и определить стартап‑файл для вашего МК.

## 📝 Заметки

- Переменная `microsec` на самом деле хранит **миллисекунды** – это исторически сложившееся название, оставленное для совместимости.
- Кнопка PA11 выполняет две функции: включает/выключает RGB‑лампу и регулирует яркость красного канала. Это может быть переделано в будущих версиях.
- Пин PA12 настроен как вход, но не обрабатывается – его можно удалить или задействовать под дополнительные функции.
- Все значения яркости лежат в диапазоне 0–127 (а не 0–255) из‑за разрядности авто‑перезагрузки таймера (128 шагов).
- Для переноса на другие STM32 потребуется скорректировать имена выводов и каналов таймеров.
