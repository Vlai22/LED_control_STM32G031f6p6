# 💡 Bare‑metal lamp controller (STM32G0, LL+CMSIS)

Проект управления освещением на STM32G031 с использованием **только LL‑драйверов и CMSIS** (без HAL).  
Реализовано плавное включение двух монохромных ламп и одной RGB‑лампы с независимой регулировкой яркости.

## ✨ Возможности

- Два независимых канала монохромного света (Lamp1, Lamp2).
- Один канал RGB (красный, зелёный, синий).
- Плавное включение ламп с настраиваемым конечным уровнем яркости.
- Изменение яркости кнопками с автоматическим реверсом при достижении предела.
- Программный антидребезг и удобное управление через битовые флаги состояния.
- Полностью ручная конфигурация тактирования и периферии (никаких `HAL_Init()` или CubeMX‑кода в рантайме).

## 🔧 Аппаратная часть

### Используемое железо

- **Микроконтроллер**: STM32G031 (семейство STM32G0x1, ядро Cortex‑M0+).
- **Плата**: любая плата с данным МК (проект тестировался на отладочной плате с кварцем? укажи здесь, если нужно).
- **Выходы ШИМ** (подключаются к силовым ключам/драйверам ламп):
  - PA0 → TIM2_CH1 – Lamp1
  - PA1 → TIM2_CH2 – Lamp2
  - PA2 → TIM2_CH3 – LampR (красный)
  - PA3 → TIM2_CH4 – LampG (зелёный)
  - PA4 → TIM14_CH1 – LampB (синий)
- **Кнопки управления** (подтяжка к земле через LL_GPIO_PULL_DOWN):
  - PA5 – Вкл./выкл. Lamp1
  - PA6 – Яркость Lamp1 (удержание, только при включённой лампе)
  - PA7 – Вкл./выкл. Lamp2
  - PA8 – Яркость Lamp2
  - PA11 – Вкл./выкл. RGB‑лампы **и** изменение яркости красного канала
  - PC15 – Яркость зелёного канала (только при вкл. RGB)
  - PC14 – Яркость синего канала (только при вкл. RGB)
  - PA12 – зарезервирован, не используется в коде (настроен как вход)
